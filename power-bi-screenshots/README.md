# Power BI Report

The NimbusFlow Power BI report is built on the `SM POL EXECUTIVE`
semantic model and presents subscription, customer health and product
usage insights.

<img width="1398" height="467" alt="pipeline-overview" src="https://github.com/user-attachments/assets/a9fdb66f-f6ed-4af3-b7af-9bdc1b7316c2" />


## Report Pages

### 1. Executive Summary

![Executive Summary](01-executive-summary.png)

Focuses on:

 - Closing MRR
 - ARR
 - Active customers
 - New and churned MRR
 - Gross MRR churn
 - Net revenue retention
 - Monthly revenue movement


### 2. Customer Health

![Customer Health](02-customer-health.png)

Focuses on:

 - Healthy, Watch and At-Risk customers
 - MRR at risk
 - Usage decline
 - Low engagement
 - Risk drivers
 - Customer-level action lists



### 3. Product Usage Analysis

![Product Usage Analysis](03-usage-analysis.png)

Focuses on:

 - Credits consumed
 - Credit utilisation
 - API calls
 - Workflow activity
 - Usage trends
 - Customers exceeding included credits
 - Potential upgrade opportunities
